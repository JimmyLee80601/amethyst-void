Amethyst Void Admin

Big buttons, no code. Add a post, edit it, or delete it. Nothing goes live until you press Save / Publish.

Web mode: sign in with a GitHub token (see README). Your token stays in this browser tab only — it is never saved to the site, and never sent to anyone but GitHub.

Need a token? GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → New token → pick only the amethyst-void repo → Contents: Read and write. Use a short expiry and keep it to yourself.

Dell mode: open this file on your Dell, pick your Void folder, edit, then Save. Then run Publish-Void.ps1 to push it live.

No folder picked yet
If no folder is picked: Save downloads a new content.json. Copy it into your Void repo folder (replacing the old one), copy any new images into assets/, then run Publish-Void.ps1.
